# スクリーンショットの作成

[使い方へ戻る](usage.md) · [デスクトップの撮影API](automation.md#アプリのスクリーンショット)

READMEと使い方に掲載した画像は、`tests/ui/demo.ts`の架空データを使ってブラウザーハーネスを撮影したものです。モデルの精度や実曲の解析結果を示す画像ではありません。製品ビルドにはデモデータを含めません。

## 公開画像を更新する

1. `npm ci`の後、`npm run dev`を起動する。
2. `http://127.0.0.1:1430/tests/ui/?demo`を開く。モデルや音源の準備は不要。
3. 保存した曲の「デモソング」を開き、通知を閉じる。
4. 時間軸上の「朝の光が 窓をたたく」を選択する。
5. ヘッダーでライトを選び、ブラウザーの全ページ撮影で`docs/images/light-mode.jpg`を保存する。
6. ダークに切り替えて`docs/images/dark-mode.jpg`を保存する。
7. 画像を開いて文字やレイアウトを確認し、README・使い方のリンクを確認する。

`?demo`を省略したハーネスは、`harness:prepare`でコピーした実データを読み込みます。公開画像の作成には必ず`?demo`を付けてください。デモの再生ボタンは音を出しません。編集はメモリー内にだけ保存され、再読み込みで元に戻ります。

## ネイティブウィンドウを撮る

実際のTauriウィンドウは`capture_app`を使います。Windows上のメインウィンドウだけを撮影するため、ブラウザーの全ページ撮影とは写る範囲が異なります。撮影条件、返り値、保存先は[APIの説明](automation.md#アプリのスクリーンショット)を参照してください。
