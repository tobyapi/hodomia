# 公開前の情報確認

確認日: 2026-09-21。

## 公開用の整理

Git作者・コミッター情報と解析run IDは、指定により保持する。個人のホームディレクトリ、開発PCの配置、別プロジェクト名、実曲名、個別の操作記録を公開用の表記へ整理する。

曲名は検証曲A/B、テスト用パスは架空の日本語パスへ置き換える。MCP設定例では環境変数からDownloadsを参照する。既存の検証値とその限界、上流スキルの著作権表示は保持する。

過去のGit履歴も同じ方針で整理した。復元用バックアップはGit除外対象の`test-results/`内に保存し、公開物へ含めない。リモートへの反映は別作業とする。

## 調査範囲

整理前のGit追跡中231ファイル、全ローカル参照から到達できる25コミット・435個のファイル内容を検査した。同じ内容のGitオブジェクトは一度だけ検査し、コミットの作者・コミッターとメッセージも確認した。

秘密鍵の開始行、代表的なGitHub/OpenAI/Anthropic/Hugging Face/AWS/Slackトークン、認証値の代入、認証情報付きURL、メールアドレス、ホームディレクトリのパスをパターン検索した。認証関連語とローカルパスはソースも確認した。専用の秘密情報スキャナーは未導入で、この検索による未検出は秘密情報が存在しない保証ではない。

検査したファイル内容では、上記パターンに合うAPIトークン・秘密鍵・認証値の代入・認証情報付きURLは見つからなかった。到達可能な履歴のファイル名には、音源、モデル重み、`.env`、秘密鍵、ZIP/7zはなかった。NULを含むバイナリとして検出したのはアプリアイコン2点だけで、1MB超のGit blobもなかった。

到達不能なGitオブジェクト、reflog、外部サービス上のPR・Issue・CIログ・リリース添付は初回検査の対象外。Git除外ディレクトリの内容は全件走査していない。

## 公開対象の取り出し

`.runtime/`、`test-results/`、`src-tauri/target/`などはGit除外対象。ただし作業フォルダーを丸ごとZIPにすると、実曲や解析結果、モデル、履歴のバックアップまで含む可能性がある。公開用ファイルはGit追跡対象を基準に作る。

現在の`.gitignore`には`.env`や任意の場所の音源を一律に除外するルールはない。秘密情報検出のフック・CIとあわせ、今後の追加候補になる。

## OSS化に関する未確認事項

リポジトリ本体の`LICENSE`はなく、`package.json`と`src-tauri/Cargo.toml`にもライセンス指定がない。同梱スキル2件のLICENSEは保持されているが、本体のライセンスは未選定。

[使い方](usage.md)にあるとおり、BTCモデル重みの商用利用・再配布条件は未確認。依存ライブラリ・各モデル・配布バイナリの条件を網羅した調査も今回の範囲外。ソースの公開と、モデルや依存物を含むインストーラーの配布は分けて確認する。

## JSONを共有する場合

`analysis/project_export.py`はスナップショット全体を書き出す。絶対パス、曲名、原本ファイル名、歌詞・手入力、失敗メッセージ、モデル来歴を含み、匿名化処理はない。OSSのサンプルには[JSON形式ドキュメント](json-format.md)の架空データを使う。

[JSON形式ドキュメント](json-format.md)の架空JSONは構文と行データを検証し、実際の書き出し処理の出力と一致することを確認した（テスト用の`root`のみ差し替え）。説明追加時の`npm run check`は全95テストと各品質検査が成功した。
